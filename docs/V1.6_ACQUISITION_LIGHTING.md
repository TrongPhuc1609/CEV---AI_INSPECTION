# V1.6 Image Acquisition & Lighting

V1.6 defines the production boundary between physical image acquisition and the inspection core.

## Acquisition contract

Every frame entering inspection must carry:

- frame ID
- product ID
- acquisition timestamp
- camera ID
- trigger ID when available
- exposure metadata when available
- lighting profile when available

A frame without identity or a valid timestamp is rejected before Vision/Rule processing.

## Commissioning readiness

Camera, trigger and lighting health are explicit. Only a fully READY acquisition chain may be used for physical commissioning.

Vendor SDKs stay behind the existing adapter layer. The core consumes `AcquiredFrame`, not vendor-specific image objects.

## Next physical step

The next commissioning run must record real camera acquisition timestamps, trigger timestamps, exposure/strobe state and measured image-to-decision latency. No mock device may be reported as physical commissioning evidence.
