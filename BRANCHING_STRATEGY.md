# Branching Strategy

`main`: stable/reviewed integration branch.

Feature branches:
- `feature/rule-cmd-v1`
- `feature/inspection-plan`
- `feature/genicam-camera`
- `feature/yolo-adapter`
- `feature/grease-segmentation`
- `feature/plc-opcua`

Bug fixes: `fix/<short-description>`
Hot fixes: `hotfix/<short-description>`

Rule: AI contributors must not directly edit `main`. Use a feature branch and Pull Request.
